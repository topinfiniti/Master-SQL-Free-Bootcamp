A collection of SQL scripts, practice exercises, datasets, and learning resources for Master SQL Bootcamp, focused on practical SQL skills and real-world business problem-solving.

# Master SQL Bootcamp 🚀

**Learn SQL. Solve Problems. Unlock Opportunities.**

Welcome to the official repository for **Master SQL Bootcamp**, a free learning initiative designed to equip young people, aspiring data analysts, and business professionals with practical SQL skills.

This repository contains SQL scripts, practice exercises, and learning resources to help learners understand SQL concepts and apply them to real-world data problems.

## 🎯 Our Mission

To empower young people and business professionals with practical SQL skills to analyse data, solve business problems, and make informed decisions.

## 📚 What You'll Learn

The repository is organised around the following topics:

- **SQL Fundamentals:** `SELECT`, `WHERE`, `ORDER BY`, and `DISTINCT`
- **Aggregate Functions:** `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`
- **Grouping and Filtering:** `GROUP BY` and `HAVING`
- **Joins:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `FULL OUTER JOIN`
- **Set Operators:** `UNION`, `UNION ALL`, and `INTERSECT`
- **Conditional Logic:** `CASE` statements
- **Subqueries and CTEs:** Writing structured and reusable queries
- **Window Functions:** `ROW_NUMBER`, `RANK`, `DENSE_RANK`, running totals, and more
- **Date Functions:** Working with dates and time-based analysis
- **Practical Projects:** Applying SQL to sales, finance, operations, and other business datasets

## 🛠️ Tools and Technologies

- **SQL Server:** Primary database platform for practical exercises.
- **SQL Server Management Studio (SSMS):** For writing and executing SQL queries.
- **GitHub:** For accessing scripts, tracking updates, and sharing learning resources.

## 🚀 Getting Started

1. Install SQL Server and SQL Server Management Studio (SSMS), or use another compatible SQL learning environment where appropriate.
2. Clone or download this repository.
3. Navigate to the topic you want to learn.
4. Open the `.sql` script in your SQL editor.
5. Execute the queries against the required sample database.
6. Modify the queries, experiment with different conditions, and practise the exercises.

**Tip:** Run scripts against a practice database rather than a production database. Check each script for its database and table requirements before executing it.

## 💡 How to Use This Repository

Whether you are learning SQL for the first time or strengthening your analytical skills, you can use this repository to:

- Follow the topics sequentially.
- Practise SQL syntax and query-writing techniques.
- Solve exercises designed around practical scenarios.
- Understand how SQL supports data analysis and business reporting.
- Build a foundation for further learning in data analytics, business intelligence, and data engineering.
